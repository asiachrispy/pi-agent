# D-2026-005 审查并优化 wiki 与 team 设计方案

## 意图

审查 pi-agent 工作区 wiki 目录 + team agent 协议，发现冗余/不一致并优化。

## 契约

- 范围：仅改 pi-agent 工作区（wiki/ + .pi/），不动 pi / pi-app。
  - summary.md 从 8KB → ≤3KB（移除与 team-decisions/agent-reading-map 重复段）
  - APPEND_SYSTEM.md 从 30 行 → 4 行重定向
  - "先读 summary" 从 6 处 → 2 处
  - 3 个空壳 README 加内容
- 不做：不改 pi / pi-app / CHANGELOG。

## 审查发现（7 项）

1. **"先读 summary" 重复 6 次跨 4 文件**（team.md / APPEND_SYSTEM.md / agent-reading-map.md / summary.md）
2. **team.md vs APPEND_SYSTEM.md 80% 重叠**（同 30+ 关键词）
3. **summary.md 8KB 远超"快查表"设计**（目标 2-3KB）—— 内含决策树/技能矩阵/子目录/路由原则，已分散在其他 wiki
4. **3 个空壳 README**（prototypes/exec-specs/prd README.md 各 100-300B）
5. **决策点概念散落 4 个文件**
6. **human_confirmation 定义在 3 处**
7. **内容金字塔倒挂**（最大的 8KB 是"快查"；最小的 118B 是最重要的模板）

## 优化方案

| # | 动作 | 文件 | 预期效果 |
|---|---|---|---|
| 1 | summary.md 从 8KB→2.5KB | wiki/summary.md | 决策树/技能矩阵/子目录迁到 team-decisions/team.md/project-map |
| 2 | APPEND_SYSTEM.md 从 30 行→5 行重定向 | .pi/APPEND_SYSTEM.md | 消除与 team.md 80% 重叠 |
| 3 | "先读 summary" 从 6→2 处（仅 agent-reading-map §总原则 + team.md §知识库） | agent-reading-map.md / team.md / APPEND_SYSTEM.md | 单点真理 |
| 4 | 清理空壳 README 标 "待填充" | wiki/prd/README.md / exec-specs/README.md / prototypes/README.md | 减少迷惑文档 |
| 5 | 统一 human_confirmation 定义到 release.md | team.md / release.md / decisions.md | 单点真理 |

## 交付

### 1. summary.md 精简（8380B → 2916B，-65%）

移除段（已分散到其他 wiki）：
- 决策树 → `wiki/decisions/team-decisions.md`（已有）
- skill 触发矩阵 → `team.md §知识库`（已含）
- 子目录速查 → `project-map.md`（已含）
- 「只读必要文档」原则 → `agent-reading-map.md`（已含）

保留段：snapshot + 关键命令（验证/Demand/Release）+ 已知陷阱（7 条，含决策点默认值）

### 2. APPEND_SYSTEM.md 精简（1537B → 280B，-82%）

从 30 行详细协议（与 team.md 80% 重叠）→ 4 行重定向：「完整规范见 `.pi/agents/team.md`」

### 3. 「先读 summary」从 6→2 处

- 移除：`agent-reading-map.md` 的 `depends_on` 中的 `summary.md`
- 移除：`agent-reading-map.md` 路由表中重复的「全部任务类型**先读 `summary.md`**」行
- 保留：`agent-reading-map.md §总原则` 第 1 条 + `team.md §知识库` 第 1 条

### 4. 空壳 README 补内容

- `wiki/prd/README.md`：299B → 266B（加关联引用）
- `wiki/exec-specs/README.md`：160B → 241B（加说明 + 关联）
- `wiki/prototypes/README.md`：118B → 277B（加说明 + 关联）

### 5. 统一 human_confirmation 定义

保留在 `.pi/protocols/release.md`（单点真理）；`team.md` 只引用不重复定义。

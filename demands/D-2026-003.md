# D-2026-003 聊天输入折叠 expanded /team prompt 为短指令

## 意图

- 背景：用户在 pi-app 聊天输入框粘贴 `pi-agent /team` 入口 prompt（expanded 模板）时，会话历史里也回放一长串模板文本，影响阅读。本需求让 `displayUserMessageText` 把 expanded `/team` 入口模板折叠为短指令 `/team <args>`。
- 触发：与 D-2026-002 一起被 `git status` 暴露出来，原本混在 D-2026-002 工作区，按 A1 决策拆为独立 demand。

## 契约

- 范围：
  - `pi-app/lib/user-message-display.ts`：新增 `collapseExpandedTeamPrompt(raw: string): string | null`；在 `displayUserMessageText` 中先于既有 `SLASH_SKILL_RE` 之外的 SKILL_BLOCK 折叠之前调用。
  - `pi-app/lib/user-message-display.test.ts`：新增用例覆盖「legacy expanded /team prompt 折叠为 /team ...」与「无需求节时折叠为 /team」。
  - 仅识别以「你是 pi-agent 的 \`/team\` 入口」开头的模板，提取「## 需求：」之后的文本作为参数；无参数则折叠为 `/team`。
  - 不影响其他 skill block、文件引用、附件折叠行为。
- 不做：
  - 不动其他已存在 skill 折叠逻辑。
  - 不动 i18n / 文案（折叠后端是英文 `/team`，对应 slash command）。
- AC：
  - AC-1 输入 `你是 pi-agent 的 \`/team\` 入口... ## 需求：D-2026-002 verify` → 输出 `/team D-2026-002 verify`。✔（已有单测）
  - AC-2 输入「## 需求：」后为空 → 输出 `/team`。
  - AC-3 输入非 `/team` 入口模板 → 不折叠（透传）。
  - AC-4 `npx tsc --noEmit`、`npx vitest run` 全绿。
- 风险：
  - 误折叠：仅当文本以 TEAM_PROMPT_HEADER 开头才触发，影响面小。

## 交付

- 改动仓库：`pi-app`
- 改动文件：
  - `pi-app/lib/user-message-display.ts`（+18 行：新增 `TEAM_PROMPT_HEADER` 正则、`collapseExpandedTeamPrompt` 函数、`displayUserMessageText` 调用点）
  - `pi-app/lib/user-message-display.test.ts`（+7 行：新增折叠用例）
- 验证命令与结果（2026-06-16 11:30）：
  - `cd pi-app && npx tsc --noEmit` → 无输出（pass）
  - `cd pi-app && npx vitest run` → `Test Files 54 passed (54)` / `Tests 256 passed (256)`（pass；其中 `lib/user-message-display.test.ts` 5 passed，新增 1 用例覆盖 expanded /team 折叠）
- 未验证项：
  - 浏览器视觉（折叠后 chat 渲染）未手动确认。

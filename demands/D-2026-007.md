# D-2026-007 左侧项目下拉菜单添加删除项目按钮（软删除，保留 session）

## 意图

- 用户原话:「左侧项目列表,想要移除怎么办」 → 「添加一个删除项目按钮,按流程执行」
- 现状:`SessionSidebar` 顶部项目下拉(`projectCwds`)完全派生自 `~/.pi/agent/sessions/` 下的 session 文件,没有任何 UI 入口可以让用户**从下拉里移除一个项目**;用户要"移除"只能去文件系统 `rm` 所有 session,可读性差、易误删。
- 目标:在下拉每个项目右侧加 `×` 按钮,点击后**该 cwd 不再出现在项目下拉里**;session 文件**不被删除**,数据可恢复。
- 归属:仅改 `pi-app`,不动 `pi` 引擎。

## 设计要点(给 team agent 落地参考)

```ts
// 1. PiWebPreferences 新增字段
export interface PiWebPreferences {
  // ... 既有
  /** Project cwds the user explicitly hid from the project picker. Session
   *  files are preserved — only the picker hides them. Falsy/empty = show all. */
  excludedProjectCwds?: string[];
}

// 2. 后端过滤(在 listProjectCwdsForPicker 里)
const prefs = loadPiWebPreferences();
const excluded = new Set(prefs.excludedProjectCwds ?? []);
return cwds.filter((cwd) => !excluded.has(cwd));

// 3. SessionSidebar × 按钮(伪代码)
<button
  onClick={(e) => {
    e.stopPropagation();
    if (cwd === filterCwd) return;  // AC-5
    addExcludedProjectCwd(cwd);      // 乐观更新本地 + 后端
    setProjectCwds((prev) => prev.filter((c) => c !== cwd));
  }}
  title={t("sessionSidebar.removeProject")}
  style={{ color: hover ? "var(--danger)" : "var(--text-dim)" }}
>×</button>
```

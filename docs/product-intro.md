## 一句话

**Pi.Agent 把企业知识变成每个岗位都能调用的 AI 工作入口 — 统一知识库、统一调度智能体、统一沉淀任务过程。**

---

## 为谁而生

- **老板 / 管理层** — 工具太多、知识太散、AI 用不起来  
- **销售 / 外贸** — 要基于真实产品资料写邮件、答客户  
- **运营 / 电商** — Listing、广告、SOP 查询  
- **客服** — 标准话术 + 异常升级  
- **产品 / 研发 / IT** — 需求、文档、协作可追溯  

---

## 核心能力

1. **企业知识库** — 文档、SOP、FAQ、项目记录统一挂载  
2. **智能体工作台** — 自然语言发起任务；插件 + MCP + 浏览器  
3. **会话与任务管理** — workspace、session、状态可追溯  
4. **Livo 协同** — Livo SSO 登录；会议待办一键派发与回写  
5. **本地优先** — 可控部署；Enterprise 可私有化  

---

## 典型场景

| 场景 | 输入 | 输出 |
|------|------|------|
| Livo 待办执行 | 会议 action item | Pi run + 状态回 Livo |
| 销售 KB | 产品 PDF | 邮件草稿、FAQ |
| 运营 SOP | 内部文档 | Listing/广告建议 |
| 客服升级 | 工单 + KB | 标准回复 |

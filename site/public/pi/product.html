Pi.Agent 是什么

Pi.Agent（pi-app）是一款 企业知识库 + 智能体工作台 SaaS —— 专门帮 10–50 人团队把分散知识变成可调度、可沉淀的 AI 工作入口。

它会把企业日常工作中需要的四件事，统一到一个 workspace 里：

  • ▸挂载知识（文档、SOP、FAQ、项目记录）
  • ▸调度 Agent（自然语言发起；插件 + MCP + 浏览器）
  • ▸协同 Livo（SSO 登录；会议待办一键派发与状态回写）
  • ▸沉淀过程（workspace、session、任务状态全程可追溯）

工作原理：四步，从知识到可执行 Agent 任务

Pi.Agent 的操作逻辑与日常工作流一致 — Livo 用户零额外账号，打开即用。

1

Livo SSO 登录

打开 pi.gottao.com/app，未登录自动跳转 Livo，ticket 换取 Pi 会话，无需重复注册。

2

挂载企业知识库

上传文档、粘贴 URL，或挂载 SOP / FAQ / 产品资料。RAG 让 Agent 回答基于真实企业内容。

3

发起任务或接收 Livo 待办

工作台自然语言提问；或从 Livo 会议 action item 一键派发到 Pi workspace，deep link 直达执行页。

4

Agent 执行 + 状态回写

插件、MCP、浏览器完成 run；session 全程可追溯。running / failed / done 自动回写 Livo，形成闭环。

Livo 协同亮点

Pi.Agent 与 Livo 深度集成：Livo SSO 作为统一身份层；会议待办派发 将 action item 直接送入 Pi workspace；执行完成后 状态自动回写 Livo，让会议决议真正落地。

Phase 1 价值公式：把一份企业资料或一条会议待办交给 Pi → 在可追溯的 workspace 里跑出结果，并能回写 Livo。

典型使用场景

从 Livo 待办执行到销售知识库，四种常见落地方式。

场景 A · P0

Livo 会议待办自动执行

输入：Livo 会议 action item（如「整理竞品对比表」「起草客户跟进邮件」）。

用法：会议中一键派发到 Pi workspace，Agent 在隔离目录执行，状态实时回写 Livo。

输出：可追溯 run 结果 + Livo 待办状态更新，会议决议不再停留在文档里。

场景 B

销售知识库问答与邮件草稿

输入：产品 PDF、规格表、FAQ、历史邮件模板。

用法：挂载 KB 后直接提问或生成开发信；可与 DTEye 线索任务联动跟进。

输出：基于真实资料的邮件草稿、FAQ 答复，新人也能稳定输出。

场景 C

运营 / 电商 SOP 查询

输入：Listing 规范、广告投放 SOP、竞品分析模板。

用法：运营在工作台查询 SOP 或请 Agent 生成 Listing / 广告建议。

输出：标准化建议与复盘，减少重复查文档与 copy-paste。

场景 D

客服标准回复与异常升级

输入：售后 SOP、工单描述、知识库 FAQ。

用法：客服基于 KB 生成标准回复；复杂 case 给出升级建议；Voice Agent 共用同一 KB。

输出：一致的话术质量 + 可追溯的处理记录。

常见问题

Pi.Agent 和 ChatGPT / Copilot 有什么区别？

Pi.Agent 不是泛化对话工具，而是企业知识库 + Agent 工作台：挂载自家资料做 RAG，任务在 workspace 里可追溯，并与 Livo 会议待办打通。你得到的是「可协作的企业 AI 入口」，不是个人聊天窗口。

必须用 Livo 才能用 Pi 吗？

Phase 1 以 Livo SSO 为主要登录方式，Starter 面向 Livo 用户开放免费 workspace。Enterprise 将支持 SAML SSO 等独立身份体系。会议待办派发与状态回写需 Livo 协同。

Livo 会议待办怎么派发到 Pi？

在 Livo 会议中创建的 action item 可一键派发到 Pi workspace，系统生成 deep link 直达执行页。Agent 运行后，running / failed / done 状态自动回写 Livo，无需人工同步。

知识库支持哪些格式？

支持文档上传与 URL 挂载，覆盖 PDF、Word、网页等常见格式。Team / Business 提供更高 KB 容量与多知识库管理；具体限制以产品内公示为准。

Agent 能连接企业内部系统吗？

Business 套餐提供 MCP 企业连接器，可对接 CRM、内部 API 等。Enterprise 支持专属 MCP 集成与私有化部署，数据可留在内网。

和 DTEye、Voice 是什么关系？

同属 Gottao 生态的独立产品：DTEye 负责 TikTok 外贸线索发现，可将跟进任务派发 Pi；Voice 外呼 Agent 与 Pi 共用知识库；Livo 提供统一身份与会议协同。各产品可单独订阅。

数据存在哪里？能否私有化？

SaaS 版 workspace 按 tenant 隔离存储；Pi 使用独立 cookie 会话。Enterprise 提供 VPC 私有化镜像部署，满足内网与合规要求。详情请联系销售。

如何衡量团队是否真正在用？

我们以 WAAT（Weekly Active Agent Tasks）为核心指标：付费 tenant 内每周完成至少一次「有明确输入、输出、状态更新」的 Agent 任务数。试用阶段建议完成 3 次成功任务后再评估 Team 升级。
